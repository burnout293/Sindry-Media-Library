# Avancement

Les infographies d'avancement du projet Sindry : versions, dates, tâches en cours, en attente
et mises de côté, décisions qui attendent l'utilisateur. Le site les montre en tête de la
page d'accueil : <https://burnout293.github.io/Sindry-Media-Library/#suivi>.

| Règle | Détail |
|---|---|
| Nom | `AAAA-MM-JJ_avancement.html`, une infographie par relevé ; on n'écrase jamais un ancien relevé |
| Format | HTML autonome : polices et logo depuis `../mockups/_ressources/`, aucune ressource externe |
| Contenu | Les six parties (App Windows, App Linux, Scripts Win, Scripts Linux, OS, Médias), les versions, les dates, le chemin critique, les décisions numérotées |
